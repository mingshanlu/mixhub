# SKYBREAK 1945｜破空者 1945
## 遊戲企劃書 v2.0

- 遊戲類型：直向捲軸射擊、Bullet Hell、Roguelite
- 平台：PC（滑鼠操作）、手機（觸控操作）
- 文件版本：2.0（企劃基礎版）
- 目前可玩版本：2.5.1

> **命名理念：**「1945」致敬經典街機縱向飛機射擊遊戲的視覺與遊玩感受；「Skybreak」代表突破經典框架，加入 Roguelite 武力組合、永久成長與逐步提高的挑戰。遊戲採復古街機射擊美術方向，飛機、敵人、角色、素材與 Logo 生成設計。

---

# 1. 遊戲核心概念

玩家操作戰機，在直向捲動戰場中持續迎戰敵機與 Boss。武器自動發射，玩家主要專注移動、閃避與使用炸彈。戰鬥中取得武力升級，組合不同 Build。

核心循環：

1. 開始戰鬥。
2. 擊敗敵人並累積分數。
3. 撿取武力升級道具，進行三選一強化。
4. 每隔一段時間迎戰 Boss。
5. 擊敗 Boss 後取得固定強化，並提高後續敵人難度。
6. 死亡或完成星區時，將本場得分加入累計總分，依永久點數門檻領取點數。
7. 使用永久點數強化戰機，再次挑戰。

設計原則：
- 操作簡單、決策有深度：武器自動攻擊，玩家專注走位與強化選擇。
- 彈幕密集但可讀：敵我子彈使用不同色系與攻擊形狀辨識；目前敵人攻擊不顯示預警。
- Build 逐步成形：每場透過三選一組合武力。
- 長期成長：永久屬性提供持續進步，但不取代玩家操作。
- 難度持續成長：Boss 擊敗數影響敵人數量、子彈速度、數量與攻擊頻率。
- 星區進度：完成當區全部 Boss 後結束本場，並解鎖下一個星區。

| 平台 | 操作 |
|---|---|
| PC | 滑鼠移動控制戰機 |
| 手機 | 手指滑動控制戰機 |
| 全平台 | 武器自動發射 |
| 全平台 | 獨立炸彈按鈕 |

玩家不需要按射擊鍵。基礎射擊間隔為600ms，但各武力可有獨立基礎射擊間隔。炸彈以遊戲區左鍵雙擊／觸控雙擊發動，Space 仍可使用；遊戲畫面不再顯示獨立炸彈按鈕，右上角以圖示列顯示剩餘炸彈，能力槽置中。首頁說明使用畫面雙擊或 Space 引爆。

# 3. 玩家戰機

## 3.1 生命與受傷

| 項目 | 數值 |
|---|---:|
| 初始生命 | 3 |
| 永久升級後最高生命 | 8 |
| 每次受傷 | -1 |
| 受傷後無敵時間 | 1.5秒 |

受傷來源包括敵人子彈與敵機／Boss 接觸。所有受傷來源共用1.5秒無敵時間。建議無敵期間戰機閃爍；無敵期間可穿過敵人，不會重複受到接觸傷害。

## 3.2 機動性與操作延遲

| 等級 | 追隨時間常數 |
|---|---:|
| Lv.0 | 0.40秒 |
| Lv.1 | 0.32秒 |
| Lv.2 | 0.24秒 |
| Lv.3 | 0.16秒 |
| Lv.4 | 0.08秒 |
| Lv.5 | 0秒（直接跟隨指標座標）|

Lv.0～Lv.4 使用平滑追隨，等級越高越貼近滑鼠或觸控位置。Lv.5 在收到新的指標座標時直接更新戰機座標，不再套用平滑延遲。所有等級仍受戰場邊界限制。
# 4. 炸彈系統

## 4.1 基本規格

| 項目 | 數值 |
|---|---:|
| 初始持有量 | 2顆 |
| 最大持有量 | 6顆 |
| 初始攻擊力 | 1 |
| 攻擊力最高值 | 7 |
| 攻擊力升級次數 | 最多6次 |
| 爆炸傷害範圍 | 約畫面60% |
| 爆炸視覺持續時間 | 約1秒 |
| 引爆後玩家無敵 | 1秒 |

炸彈由玩家主動觸發，使用獨立按鈕，不占能力槽。

## 4.2 清彈與傷害判定

- 引爆瞬間清除畫面上所有敵人子彈。
- 全畫面清彈不受爆炸傷害範圍限制。
- 爆炸傷害只對約60%畫面範圍內的敵人造成傷害。
- 清彈範圍與爆炸傷害範圍是兩套獨立判定。
- 爆炸傷害於引爆瞬間結算一次。
- 建議以玩家為中心的圓形爆炸呈現，直徑約為畫面寬度的60%。
- Boss 正常受到炸彈傷害。

## 4.3 炸彈強化

三選一可能出現炸彈數量+1或炸彈攻擊力+1。
- 持有量達6顆時，不再提供增加炸彈數量。
- 攻擊力達7時，不再提供炸彈攻擊力升級。
- 炸彈不占能力槽。

# 5. 永久成長系統

永久屬性由跨場保留的永久點數購買；點數依累計總分門檻取得。死亡或完成當前星區時，本場最終得分都會加進累計總分。最高分另作紀錄，不再用來計算點數。

# 5.1 六項永久屬性

| 屬性 | 初始值 | 最高值 | 升級效果 |
|---|---:|---:|---:|---|
| 機動性 | Lv.0 | Lv.5 | 追隨常數由0.40秒逐步降至0秒；Lv.5直接跟隨指標 |
| 能力槽 | 3格 | 8格 | 每級增加1格 |
| 生命 | 3 | 8 | 每級增加1點生命 |
| 武力發射速度 | Lv.0 | Lv.5 | 每級發射頻率增加6% |
| 暴擊幾率 | 5%（Lv.0） | Lv.5：30% | 每級增加5個百分點 |
| 暴擊傷害 | Lv.1：1.1倍 | Lv.5：5倍 | Lv.2為2倍，Lv.3～5每級增加1倍 |

暴擊可套用於玩家武力造成的傷害；每次傷害判定依暴擊幾率抽選，暴擊時依暴擊傷害等級乘算，並在目標上方以桃紅色顯示「暴擊 -傷害值」。炸彈對每個目標的傷害也會獨立判定暴擊。

## 5.2 永久升級花費

一般屬性每次升級依序花費1、2、3、4、5點。暴擊傷害以Lv.1、1.1倍作為初始值，升級至Lv.2～Lv.5分別花費1、2、3、4點。

| 單項升級 | 花費點數 |
|---|---:|
| 一般屬性升滿（Lv.0至Lv.5） | 15 |
| 暴擊傷害升滿（Lv.1至Lv.5） | 10 |
| 四項原有屬性升滿 | 60 |
| 六項屬性全部升滿 | 85 |

機庫提供「重置點數」功能，會退還所有已投入永久屬性的點數，並將屬性等級重置，供玩家重新分配。累計總分已取得的永久點數總數不會因此改變。
## 5.3 永久射速公式

T = 600 / (1 + 0.06 × L)

T：最終射擊間隔（ms）
L：永久射速等級（0～5）
每級射速頻率增加 6%。

| 永久射速等級 | 基礎間隔 |
|---|---:|
| Lv.0 | 600ms |
| Lv.1 | 約566ms |
| Lv.2 | 約536ms |
| Lv.3 | 約508ms |
| Lv.4 | 約484ms |
| Lv.5 | 約462ms |

特殊武力傷害 tick 可獨立設定，不必完全套用此公式。

# 6. 累計總分與永久點數門檻

- 四種星區共用最高分、累計總分與永久點數。
- 每場死亡結算或完成星區時，將本場最終得分加入累計總分；重複遊玩也會累計。
- 每跨過一個門檻取得1點；單次結算跨越多個門檻時，一次補發全部點數。
- S₀ 取自第一隻 Boss 出現前，玩家實際取得的分數，於首隻 Boss 出現時記錄為基準。
- 門檻倍率由程式參數 `PARAMS.progression.permanentPointScoreMultiplier` 控制，目前1.178，可集中修改。

公式：

ScoreThreshold_n = ceil(S₀ × R^(n − 1))（目前 R=1.178）

R：可調整的永久點數門檻倍率參數，目前設定為1.178。
S₀：第一隻 Boss 出現前記錄的實際分數。
n：永久點數門檻編號，從1開始。
門檻向上取整數。六項永久屬性全部升滿需85點；若 S₀=1,500，第85點門檻約為累計總分1,420,023,910。

**舊存檔轉換：** 先前版本沒有記錄累計總分，因此第一次載入時以原有最高分作為累計總分起始估值；之後每場分數都會正常累計。

# 7. 四種恆星星區與解鎖進度

| 星區 | Boss數量 | 敵方生命倍率 | 分數倍率 | 背景風格 |
|---|---:|---:|---:|---|
| 藍超巨星 | 10隻 | ×1 | ×1.0（不變） | 藍色超巨星與星雲弧帶 |
| 黃矮星 | 12隻 | ×2 | ×1.1（+10%） | 黃矮星與小行星帶 |
| 紅巨星 | 14隻 | ×3 | ×1.2（+20%） | 紅巨星與日珥弧 |
| 中子星 | 26隻 | ×4 | ×1.3（+30%） | 脈衝光束與碎石軌道 |

每區 Boss 數量為偶數，小 Boss 與大 Boss 交替出現。星區生命倍率套用於敵人；Boss 生命依出現時玩家本場分數計算。分數增益直接乘於本次得分，倍率分別為×1.0、×1.1、×1.2、×1.3。四區背景具備不同星體、星雲、日珥、小行星與脈衝地貌輪廓。

解鎖與結算：
- 擊敗當區最後一隻 Boss 並完成獎勵選擇後，該場立即結束，並解鎖下一星區。
- 已解鎖星區可重複挑戰；四區共用最高分、累計總分與永久點數。
- 最後一區完成後，顯示全區完成資訊，可重玩已解鎖星區。

# 8. 敵人系統

## 8.1 敵人類型

| 類型 | 基礎生命 | 初始類別生成權重 | 尺寸 |
|---|---:|---:|---:|
| 一般敵人 | 1 | 70% | 100% |
| 中階敵人 | 3 | 30% | 150% |
| Boss | 依Boss公式 | 不適用 | 中階敵人的200% |

## 8.2 敵人種類解鎖

- 每擊敗一隻 Boss，一般敵人新增一種類型。
- 每擊敗一隻 Boss，中階敵人也新增一種類型。
- 新種類可有不同外型、顏色、子彈數量、射擊角度、射速與攻擊模式。
- 一般敵人與中階敵人的類別生成比例維持70%／30%。
- 各類別內所有已解鎖種類平均分配權重。

## 8.3 攻擊模式

每種敵人至少設計三種攻擊模式：
1. 直線射擊。
2. 扇形射擊。
3. 斜向或交叉射擊。

攻擊模式可隨機抽取。現行版本取消敵人攻擊前預警，攻擊直接發動；以敵我子彈的顏色及直線、扇形、交叉等彈道形狀辨識威脅。

# 9. 敵人難度成長

一般敵人會持續生成；場上存活數低於上限時，每1.2秒補生成一隻，維持場上敵人數量。初始同時上限為5隻；擊敗任一小 Boss 或大 Boss 後，上限增加2隻。擊敗大 Boss 後，一般敵人與中階敵人的基礎生命各增加1。敵人子彈速度與數量逐步提高、射擊間隔縮短。彈幕密度由可調參數控制，現行基礎倍率為0.25。

- 子彈速度倍率：min(1.05^n, 1.8)。
- 子彈數量倍率：基礎數量 × min(1.05^n, 1.8) × 彈幕密度倍率；小數以機率方式取整，最少發射1顆。
- 射擊間隔：max(200ms, 600ms × 0.95^n ÷ 彈幕密度倍率)。

n：已擊敗 Boss 數量。射擊間隔下限為200ms，速度與數量成長上限為1.8倍。攻擊開始時直接發射，不顯示攻擊前預警。

# 10. Boss 系統

## 10.1 出現時間與順序

- 每經過60秒一般戰鬥時間，出現一隻 Boss。
- Boss 戰期間暫停出現計時。
- 擊敗 Boss 後重新開始60秒計時。
- 同時最多出現一隻 Boss。
- Boss 順序固定交替：小 Boss → 大 Boss → 小 Boss → 大 Boss。

## 10.2 小 Boss

- 只使用單發砲，並搭配一般敵人。
- 建議小 Boss 戰期間不生成中階敵人。
- 建議同時最多3隻一般敵人。
- 一般敵人可使用不同攻擊角度配合 Boss。
- 預估戰鬥時間30～60秒。

## 10.3 大 Boss

- 固定使用單發砲，並搭配預先設計的 Build 額外武力。
- 不受玩家本場取得武力種類限制。
- 大 Boss 戰期間停止生成一般敵人。
- 預估戰鬥時間60～120秒。
- 大 Boss 的武力組合必須經過設計，不是隨機抽取幾種武力後同時發射。

## 10.4 各季大 Boss 額外武力種類數量與 Build

大 Boss 實戰會輪替使用以下 Build 額外武力；越後期安排追蹤、分裂、雷射與衛星等壓力較強的組合。以下數量不包含固定單發砲：

| 星區 | 大 Boss數量 | 各大 Boss 額外武力種類數 |
|---|---:|---|
| 藍超巨星 | 5 | 1、1、2、2、3 |
| 黃矮星 | 6 | 1、1、2、2、3、3 |
| 紅巨星 | 7 | 1、1、2、2、3、3、3 |
| 中子星 | 13 | 1、1、2、2、3、3、3、4、4、4、4、4、4 |

## 10.5 大 Boss 攻擊限制與節奏

- 最多同時使用2種額外武力主動攻擊，固定單發砲始終存在。
- 各武力分階段輪替，必要時短暫組合。
- 現行版本不顯示攻擊前預告。
- 高威脅攻擊後至少保留1秒相對安全區。
- 只有具備兩種以上額外武力時，才安排組合階段。

建議初版攻擊循環：

| 階段 | 時間 |
|---|---:|
| 預告 | 不使用 |
| 第一武力 | 4秒 |
| 第二武力 | 4秒 |
| 組合階段 | 3秒 |
| 緩和 | 1.5秒 |
| **每輪合計** | **約13.5秒** |

只有一種額外武力時，省略第二武力與組合階段，並重新安排合理循環節奏。Boss 攻擊傷害與攻擊頻率獨立平衡，不直接複製玩家武力傷害或射速。

## 10.6 Boss 生命公式

BossHP = max(1, S × 0.05)

S：該 Boss 出現當下玩家在本場戰鬥中取得的分數。
Boss 血量為出現時分數的5%，最低為1；不使用季節生命倍率，也不依一般敵人擊殺生命值累加。小 Boss 與大 Boss 使用同一公式。

# 11. 玩家武力系統通則

- 共10種武力。
- 取得武力時為Lv.1，最高Lv.6。
- 多數武力初始傷害為1；機槍砲與分裂砲使用0.5傷害。
- 多數武力占用1格能力槽。
- 單發砲是預設武器，Lv.1不占能力槽，升到Lv.2時才占1格。
- 武力只在當場有效，死亡後清空。
- 特殊武力可使用獨立傷害判定間隔。
- 傷害系統必須支援小數，0.5傷害不得四捨五入成1。

## 11.1 武力等級抽選權重

| 武力等級 | 抽選權重倍率 |
|---|---:|
| Lv.1 | ×1.0 |
| Lv.2 | ×1.1 |
| Lv.3 | ×1.2 |
| Lv.4 | ×1.3 |
| Lv.5 | ×1.4 |
| Lv.6 | 排除抽選 |

倍率不是實際出現機率，會依可抽選選項重新正規化。Lv.6武力完全退出三選一抽選池。三選一不得重複同一選項；能力槽滿時不提供無法取得的新武力。

# 12. 十種武力詳細規格

## 12.1 單發砲

- 正前方直線射擊，初始傷害1。
- 每升一級增加一顆縱向子彈，Lv.1～Lv.6共1～6顆。
- Lv.6子彈尺寸增加30%。
- Lv.1不占能力槽，升到Lv.2開始占1格。
- 多顆子彈依序錯開發射，初版延遲為0、40、80、120、160、200ms。
- 後面子彈是較晚發射，不是飛行速度較慢。
- 滿級搭配永久射速Lv.5的預估射擊間隔約230ms。

## 12.2 機槍砲


- 每次發射形成縱向排列的3顆子彈（間距10px）；Lv.1～Lv.6每級增加一列，滿級共6列、18顆。
- 每顆子彈傷害0.5；每級射速頻率成長18.2%。
- 滿級搭配永久射速Lv.5，預估可達200ms。


## 12.3 追蹤彈

- 每級增加一顆，Lv.1～Lv.6共1～6顆。
- 追蹤轉向速度180度／秒。
- 搜尋距離為畫面高度的80%，優先追蹤最近敵人。
- Lv.6不再命中爆炸；追蹤彈射速提高100%（射擊間隔減半）。

有限追蹤規則：
- 不可180度折返。
- 標準轉向限制為原始方向左右各60度。
- 最長追蹤0.8秒，之後改為直線飛行。
- 現行追蹤彈不顯示發射前預告。
- Boss追蹤攻擊需有冷卻時間。
- 不可在臨近命中時突然大幅修正方向。
- 子彈離開畫面即消失，不重新進場。

初版基礎射擊間隔1000ms，每級射速頻率增加14%。永久射速Lv.5、局內Lv.6預估約400ms，需測試。

## 12.4 散射槍

- 扇形散射，每顆子彈基礎傷害1；Lv.6每顆子彈額外增加1點傷害。

| 等級 | 子彈數 | 散射角度 |
|---|---:|---:|
| Lv.1 | 6 | 45° |
| Lv.2 | 8 | 50° |
| Lv.3 | 10 | 55° |
| Lv.4 | 12 | 60° |
| Lv.5 | 14 | 65° |
| Lv.6 | 16 | 70° |

初版基礎間隔800ms，每級射速頻率增加17.1%，滿級預估約280ms。不另加Lv.6額外射速加成。

## 12.5 雷射槍

- 持續雷射攻擊。
- 傷害Lv.1～Lv.6為1、1.2、1.4、1.6、1.8、2。
- 傷害判定間隔200ms。
- 雷射寬度初始為玩家戰機寬度的60%，每級增加5%。
- Lv.6具備穿透能力，並移除發射間隔，持續發射雷射。
- 不直接套用一般射速公式，需單獨測試對 Boss 的每秒傷害。

## 12.6 衛星

- 衛星環繞玩家戰機，每級增加一顆，Lv.1～Lv.6共1～6顆。
- 環繞速度每級增加5%。
- 接觸敵人造成1點傷害。
- 同一顆衛星對同一敵人的傷害間隔500ms。
- 衛星可碰消敵方子彈，防禦判定半徑7px；接觸時子彈消失並顯示淡藍色火花。
- 初始軌道半徑為玩家戰機寬度的1.5倍。
- Lv.6軌道半徑額外向外擴張20%。
- 不套用一般射速公式。

## 12.7 電擊槍

- 朝正前方發動電擊並連鎖。
- 連鎖數量Lv.1～Lv.6為1～6。
- 初始傷害1，Lv.6傷害2。
- 初始攻擊間隔900ms，每級射速頻率增加9%。
- 連鎖距離為畫面寬度的25%。
- 同一次電擊不可重複命中同一敵人，優先選擇最近目標。
- 永久射速Lv.5、局內Lv.6預估攻擊間隔約450ms。

## 12.8 火焰槍

- 中近距離範圍火焰攻擊，每級攻擊範圍增加4%。
- 火焰造型子彈的基礎半徑由7px加倍為14px；每升一級再增加10%（相對Lv.1尺寸線性增加），Lv.6比Lv.1大50%。子彈本體與尾焰採半透明呈現。
- 火焰子彈可穿透敵人，飛行期間每個目標只直接命中一次；命中後仍會繼續前進並附加灼傷。
- 灼傷每秒造成1點傷害，持續3秒；灼傷可觸發暴擊。
- 灼傷傷害數字前加「灼傷」；暴擊時顯示「灼傷暴擊」及實際傷害值，使用桃紅色，普通灼傷使用橘色。
- 同一敵人不可疊加多層灼傷，重複命中只刷新灼傷持續時間。
- 火焰接觸判定間隔初版200ms，灼傷使用獨立傷害判定。
- **基礎發射冷卻時間（CD）為3000ms。**
- 永久射速與局內射速可縮短CD，最低CD為1000ms。

CD = max(1000, 3000 / ((1 + 0.06 × L) × (1 + r)^(W - 1)))

CD：火焰槍發射冷卻時間（ms）。
火焰彈半徑 = 14px × (1 + 0.10 × (局內等級 − 1))。
L：永久射速倍率。
r：火焰槍每級局內射速成長率（12.4%）。
W：火焰槍局內等級（1～6）。
最低冷卻時間 1000ms。

初版基礎射速參數為700ms、每級射速頻率增加12.4%，但火焰槍實際發射使用上述CD機制。

## 12.9 冰塊槍

- 向前方扇形發射冰塊，每組3顆，每級增加一組。
- Lv.1～Lv.6總數為3、6、9、12、15、18顆。
- **每顆傷害固定1，升級不增加傷害。**
- 一般與中階敵人減速50%；Boss減速20%。
- 減速持續2秒，重複命中刷新時間。
- 冰塊槍命中並施加減速時，在敵人上方顯示青色「減速」文字；短時間內重複命中會合併提示，避免文字過密。
- Boss最低移動速度不得低於原本速度的80%。
- 初版基礎間隔900ms，每級射速頻率增加14.6%，滿級預估約350ms。

## 12.10 分裂砲

- 發射大型能量彈，大型彈飛行0.8秒或命中後分裂。
- Lv.1～Lv.6第一次分裂數量為3、4、5、6、7、8顆。
- Lv.6小型子彈可再分裂一次。
- 第二次分裂後不得再次分裂，第二次分裂的小型子彈數量為3顆。
- **大型彈、第一次分裂小彈、第二次分裂小彈，每顆傷害均為0.5。**
- 初版基礎間隔1200ms，每級射速頻率增加13%，滿級預估約500ms。
- 必須限制單次攻擊的最大子彈數。

# 13. 一般武力射速初版數值表

以下為設計初稿，尚未經過實際遊戲測試，不是最終平衡值。

| 武力 | 基礎間隔 | 每級射速頻率成長 | 永久Lv.5、局內Lv.6預估 |
|---|---:|---:|---:|
| 機槍砲 | 600ms | +18.2% | 200ms |
| 單發砲 | 600ms | +14.9% | 230ms |
| 散射槍 | 800ms | +17.1% | 280ms |
| 火焰槍 | 700ms | +12.4% | 300ms（另受CD限制） |
| 冰塊槍 | 900ms | +14.6% | 350ms |
| 追蹤彈 | 1000ms | +14.0% | 400ms |
| 電擊槍 | 900ms | +9.0% | 450ms |
| 分裂砲 | 1200ms | +13.0% | 500ms |

一般射擊武力公式：

T = max(200, T_0 / ((1 + 0.06 × L) × (1 + r)^(W - 1)))
T：最終射擊間隔（ms）。
T_0：該武力的基礎射擊間隔。
L：永久射速等級。
r：該武力每級局內射速成長率。
W：局內武力等級。

機槍砲最快可達200ms；其他武力依定位設定不同速度。雷射與衛星不列入一般射速表。

# 14. 掉落、升級與三選一

## 14.1 Boss週期掉落

一般敵人每個 Boss 期間最多依序生成10隻；每擊敗任一 Boss，下個期間生成上限增加5隻。每擊敗一隻大 Boss，後續一般敵人與中階敵人基礎生命各增加1點（再乘星區生命倍率）。
每個 Boss 週期內：
- 隨機指定1或2隻不同敵人掉落武力升級道具。
- 掉落1次與掉落2次的機率各為50%。
- 若本週期掉落2次，必須由不同敵人掉落。
- 被指定敵人死亡時保證掉落。
- 道具沿直向捲軸方向向下移動，滑出畫面下緣即消失。
- 漏接不補發、不保留。
- 玩家受傷不會使道具消失。
- 玩家撿取道具並進入三選一時，整個戰鬥畫面與道具都暫停。

## 14.2 Boss擊敗獎勵

每擊敗一隻 Boss，固定取得一次三選一強化。因此每個 Boss 週期總強化機會為2～3次（敵人掉落1～2次，加上Boss獎勵1次）。

## 14.3 三選一內容

可能出現：
1. 取得新武力。
2. 升級既有武力。
3. 炸彈數量+1。
4. 炸彈攻擊力+1。
5. 玩家生命+1：恢復1點目前生命，不超過生命上限；受傷且生命未滿時，每次三選一有5%機率出現。

## 14.4 抽選權重

- 炸彈選項基礎權重：0.8。
- 武力取得／升級基礎權重：1.0。
- 武力升級權重再乘上武力等級倍率。
- Lv.1～Lv.5倍率分別為1.0、1.1、1.2、1.3、1.4。
- Lv.6完全排除抽選。
- 抽選前先排除無效選項，再依有效選項權重重新正規化。

## 14.5 無效選項排除

- 能力槽已滿時，不提供無法取得的新武力。
- 武力已達Lv.6時，不提供該武力升級。
- 炸彈數量達6顆時，不提供炸彈數量升級。
- 炸彈攻擊力達7時，不提供炸彈攻擊力升級。
- 玩家生命已滿時，不提供生命+1選項；生命未滿時，此選項以5%機率出現。
- 三選一不得出現重複選項。
- 有效選項不足3個時，顯示實際可用數量。
- 沒有有效選項時，不顯示三選一。

## 14.6 各季強化機會估算

| 星區 | Boss數 | 強化機會範圍 | 平均強化機會 |
|---|---:|---:|---:|
| 藍超巨星 | 10 | 20～30次 | 25次 |
| 黃矮星 | 12 | 24～36次 | 30次 |
| 紅巨星 | 14 | 28～42次 | 35次 |
| 中子星 | 26 | 52～78次 | 65次 |

8種非預設武力由未取得到滿級需要47次升級機會：單發砲由預設Lv.1升至Lv.6需要5次，其餘7種各需6次。中子星最低52次，因此有機會完成全部武力滿級，但漏接道具或選擇炸彈強化後不保證。

春、夏、紅巨星以 Build 取捨為主；中子星可提供較完整的強化體驗。

# 15. 暫停、死亡與結算

## 15.1 三選一暫停

玩家撿取升級道具時：
- 暫停敵人移動與攻擊。
- 暫停所有子彈移動。
- 暫停道具移動。
- 暫停 Boss 與一般戰鬥計時。
- 三選一完成後恢復戰鬥。

## 15.2 死亡結算

- 玩家生命歸零，立即結束本場。
- 玩家死亡後清空當場取得的武力、炸彈與臨時強化。
- 永久屬性保留。
- 將本場最終分數加至累計總分，並依可調門檻倍率（目前1.178）發放新永久點數。
- Boss戰期間死亡也直接進入死亡結算。

## 15.3 Boss擊敗

- 擊敗 Boss 後結算 Boss 獎勵。
- 若不是當區最後一隻 Boss，擊敗後重新開始60秒一般戰鬥計時。
- 難度成長依擊敗 Boss 數更新。
- 解鎖新的敵人種類。
- 擊敗星區最後一隻 Boss 並完成獎勵選擇後，立即結束本場並解鎖下一星區。

# 16. 效能、碰撞與例外處理

1. 建議使用物件池管理子彈、敵人與道具，避免大量建立／銷毀物件。
2. 離開畫面的敵人子彈自動清除。
3. 已失效或離開畫面的敵人子彈不再計算碰撞。
4. 分裂砲需限制單次攻擊最大子彈數。
5. 敵人生成量需設置上限。
6. 玩家受傷後，1.5秒無敵期間忽略重複傷害判定。
7. 傷害系統需支援小數，尤其0.5傷害不可被四捨五入。
8. 暫停時所有戰鬥物件與計時器必須一致停止。
9. Boss 與敵人目前不顯示攻擊前預警；以彈道樣式及顏色區分敵方攻擊。
10. 子彈、碰撞與傷害計算需避免同一幀重複結算。
